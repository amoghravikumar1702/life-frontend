# Purpose

Allow the AI CFO to remember businesses while respecting privacy.

---

# Memory Types

Business Memory

Customer Memory

Vendor Memory

Financial Memory

---

# Examples

Remembers

- Preferred reminder time
- Vendor payment habits
- Seasonal revenue
- Customer payment behaviour
- Cashflow cycles

Never stores

- Passwords
- Card details
- OTPs
- Secret keys

---

# Rules

Memory must be

- Relevant
- Explainable
- Deletable
- Secure

---

# Golden Rule

Memory exists to reduce repetitive work.

Not to invade privacy.
